Mooshik is an ambient AI cowork partner and workspace orchestrator. It runs continuously alongside you as a peer.

Mooshik holds lifelong memory of your workspace. It coordinates web research and connects to tools over Model Context Protocol. When you need heavy code edits, Mooshik delegates tasks to coding agents.

## The Triad Model

Mooshik separates memory, orchestration, and coding execution into three clear roles.

| Role | Responsibility |
| :--- | :--- |
| **Mooshik** | Ambient awareness, local chat, research, MCP aggregation, and terminal UI. |
| **Lambo** | Living graph memory substrate, in-memory graph, write-behind, and vector recall. |
| **Coding Contractor** | Surgical code edits in repositories under constraints provided by Lambo memory. |
